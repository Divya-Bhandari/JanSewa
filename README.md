# JanSewa – Public Service Complaint Management System

**JanSewa** is an AI-powered public service complaint management platform designed to make it easier for citizens to report, track, and manage public service issues.

The system connects **citizens, government departments, and administrators** in one platform, helping complaints reach the appropriate department and making the resolution process more organized and transparent.

## 🎯 Project Overview

JanSewa provides a digital platform where citizens can report issues such as:

* Road and pothole problems
* Broken streetlights
* Water supply issues
* Waste management problems
* Other public service complaints

Citizens can submit complaints with descriptions, images, and location information. Departments can review and manage assigned complaints, while administrators can monitor users, departments, complaints, and overall system activity.

## ✨ Key Features

### 👤 Citizen

* Register and securely log in
* Submit public service complaints
* Add complaint descriptions and images
* Select complaint locations using maps
* Track complaint status
* View complaint history
* Receive notifications and updates
* Interact with the AI assistant

### 🏢 Department

* View complaints assigned to the department
* Review complaint details
* Manage complaint status
* Handle and resolve citizen complaints
* Update complaint progress

### 👨‍💼 Administrator

* Manage users and roles
* Manage departments
* Monitor complaints
* View complaint statistics
* Oversee the complete complaint management system

## 🤖 AI-Powered Assistance

JanSewa integrates **Google Gemini AI** to provide intelligent assistance to users.

The AI assistant can help with:

* Understanding citizen complaints
* Suggesting appropriate complaint categories
* Providing helpful responses
* Guiding users through the complaint process

This makes the platform more interactive and helps users communicate their problems more effectively.

## 📍 Location-Based Complaints

JanSewa uses **Leaflet maps** to allow citizens to provide the location of a reported issue.

Location information helps departments identify where a problem has occurred and improves the efficiency of complaint handling.

## 🖼️ Image Support

Citizens can attach images to their complaints to provide visual information about the reported issue.

Images are managed using **Cloudinary**, allowing complaint-related evidence to be stored and accessed when needed.

## 🔔 Notifications

JanSewa provides notifications to keep users informed about their complaints.

Users can receive updates when:

* A complaint is submitted
* A complaint is assigned to a department
* The complaint status changes
* A complaint is resolved

The system also supports email notifications through **Nodemailer**.

## 🌐 Multi-Language Support

JanSewa includes multi-language support to make the platform more accessible to different users.

The language system manages translated:

* Interface text
* Form labels
* Error messages
* Notifications
* Other user-facing content

## 🔐 Security

The system includes authentication and role-based access control to ensure that users can access only the features appropriate to their role.

Security features include:

* JWT authentication
* Password hashing
* Role-based authorization
* Input validation
* CORS protection
* Security headers
* Rate limiting

## 🌍 Real-World Applications

JanSewa can be applied to:

* Municipal complaint management

* Government service portals

## 💡 Project Goal

The main goal of JanSewa is to **digitize and simplify public complaint management** by creating a transparent connection between citizens and government departments.

By combining complaint tracking, location services, image evidence, notifications, dashboards, and AI assistance, JanSewa aims to make public service reporting **faster, more organized, and more accessible**.
